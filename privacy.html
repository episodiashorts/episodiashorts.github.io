Privacy Policy

EpisodiaShorts Studio · last updated 31 October 2026

EpisodiaShorts Studio ("the Studio") is the production tool of the EpisodiaShorts channel. It is run only by the channel's owner, on the owner's own computer, and signs in only to the channel's own accounts. This policy explains what account data the Studio uses and how.

Google and YouTube data

The Studio asks Google for one permission: upload videos to YouTube (the youtube.upload scope). It uses it only to upload finished EpisodiaShorts episodes, with their title, description and tags, to the EpisodiaShorts YouTube channel, and to set when each one goes public.

The Studio does not read, collect or store any other Google or YouTube data: no emails, contacts, files, viewing history, comments or subscriber information.

The sign-in token Google issues is stored only on the owner's computer, is never sent anywhere except to Google, and is never shared, sold or used for advertising.

The Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Instagram data

The Studio uses Meta's Instagram API only to publish finished episodes as Reels on the EpisodiaShorts Instagram account and to read back the link to each Reel. Its access token is stored only on the owner's computer and is never shared.

Viewers and visitors

The Studio has no users other than the channel owner. This website uses no cookies, no analytics and no forms, and collects nothing about its visitors. When you watch EpisodiaShorts on YouTube or Instagram, those platforms' own privacy policies apply.

Removing access

The owner can remove the Studio's access at any time: for Google at myaccount.google.com/permissions, and for Instagram in the app under Settings, Website permissions, Apps and websites. Deleting the token files on the owner's computer also removes all stored access.

Changes and contact

If this policy changes, this page is updated and the date above changes. Questions: episodia9@gmail.com.
